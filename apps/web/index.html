Arquivos de dados abertos

    Junte arquivos do mesmo tipo (ex.: dengue de 2019 a 2023, ou internações de vários estados). Com dois ou mais, o mapa ganha a faixa Período para ver um ano de cada vez e comparar.

    Baixar os dados abertos DBF, CSV

    Extrair DBF original devolve o arquivo de dentro do DBC, sem alteração. Salvar seleção em DBF grava só os registros que passaram nos filtros. Microdatasus filtrado CSV sai no formato que o pacote do R espera. Pacote para o Lab leva a tabela mais um arquivo de procedência (origem, hash, filtros) para analisar no Tabwin Lab.

    Definições e conversões DEF e CNV

    DEF e CNV são o que transforma código em nome legível — 1 vira Masculino. O Editor de CNV cria e valida conversões; o Inspetor de DEF mostra o que um DEF aberto declara.

    Análises e tabelas salvas abrir, salvar

    Análise (.twrecipe) guarda o plano — variáveis, filtros, conversões e transformações — e reconstrói a tabela ao reabrir. Tabela (.twtable) guarda o resultado já calculado, para reabrir ou comparar depois.

    Tabular por campos modo avançado

    O Painel de tabulação, à direita, é o caminho principal. Aqui ficam os controles campo a campo, os filtros por intervalo e as ferramentas de limpeza.

    Onde todo o Brasil
    Filtros e seleções nenhum
    Escolha um campo para selecionar valores.
    Opções avançadas medidas, limpeza, transformação
    Medidas adicionais lado a lado nenhuma

    G017: o TabWin permite somar vários incrementos ao mesmo tempo, cada um em sua própria coluna. A medida acima continua sendo a primeira coluna; as adicionadas aqui entram depois, na ordem em que forem incluídas.

    Limpeza assistida não destrutiva
    Escolha um campo para ver distribuição, ausências e valores extremos.

    A sugestão apenas preenche os campos. Confira o contexto clínico antes de aplicar; o arquivo original nunca é alterado.

    Regras cruzadas nenhuma
    Condição 1
    Condição 2

    As duas condições precisam ocorrer no mesmo registro. A regra é uma política explícita do usuário e fica registrada na análise.

    Combinações raras não analisadas

    O perfil mostra frequência; raridade não significa erro.

    “Criar regra” apenas prepara uma sinalização explícita para a combinação observada. Revise o contexto antes de alternar para exclusão.

    Transformar dados nenhuma etapa

    Selecionar colunas, filtrar linhas, recodificar valores, marcar ausentes e remover duplicatas — como um pipeline reproduzível, pela interface. O arquivo original nunca é alterado; cada etapa fica no histórico abaixo até você aplicar.

    Mantém a primeira ocorrência de cada combinação; a ordem é a do arquivo aberto.

    Mesma linguagem de fórmulas da coluna calculada, sobre os campos do registro. Um resultado não finito interrompe o pipeline; use IFERROR(…; valor) para dizer o que aquele registro deve mostrar.

    Datas aceitas: AAAAMMDD, AAAA-MM-DD, DD/MM/AAAA e o campo de data do próprio DBF. Uma data impossível (31/02) não vira março em silêncio — conta como falha.

    Semana epidemiológica pela regra MMWR/MS: a semana vai de domingo a sábado, e a SE 1 é a que tem pelo menos quatro dias em janeiro. Por isso o ano epidemiológico é uma coluna à parte — o começo de janeiro pode pertencer à última semana do ano anterior.

    O código IBGE de 7 dígitos perde o dígito verificador; o de 5 ou menos ganha o zero à esquerda de volta. Um valor que não é código fica intacto e é contado — nunca apagado.

    Uma linha por combinação dos campos escolhidos. Um grupo sem valor numérico para um campo resume como "—", nunca como zero inventado. Depois de agrupar, só as chaves e os resumos continuam existindo.

    Nenhuma segunda base carregada.

    Empilha uma segunda base (CSV/TSV) abaixo da atual, unindo as colunas. Coluna que só existe de um lado fica ausente ("—") do outro — nunca um valor inventado, nunca conversão de tipo silenciosa. Para empilhar DBC/DBF do mesmo esquema, use "Combinar" ao abrir o arquivo.

    Nenhuma segunda base carregada.

    Traz as colunas da segunda base para os registros atuais, casando pela chave (os nomes podem diferir dos dois lados). Uma chave N:N — duplicada nos dois lados — é bloqueada por padrão, porque multiplica linhas. Sem correspondência, os valores trazidos ficam "—", nunca inventados.

    Visão pedagógica, só leitura: o código é derivado do pipeline, não o contrário, e não é executado. Onde a semântica do TabSis difere do R/pandas (semana epidemiológica, código IBGE, funções de fórmula), há um comentário dizendo.

                O que é cada arquivo?
                
    
                  
    .DBF
    A tabela de dados: um registro por internação, óbito, nascimento… Formato dBase, de 1980, que o DATASUS usa até hoje.
    
                  
    .DBC
    O mesmo .DBF, comprimido pelo DATASUS para baixar mais rápido. O TabSis descomprime aqui mesmo.
    
                  
    .DEF
    O "cardápio" da tabulação: diz quais variáveis aparecem em Linhas, Colunas, Incremento e Seleções, com que nome e com qual .CNV.
    
                  
    .CNV
    A tabela de conversão: transforma código em nome (1 → Masculino) e agrupa códigos (CID → capítulo, município → região).

      Sobre
      
          TabSis
          
      
          Uma reimplementação moderna, local e auditável dos fluxos analíticos do TabWin. Projeto independente; os resultados de compatibilidade são validados contra o TabWin 4.15 real, com tolerância zero.
          
      
          Manual do usuário — como tabular, filtrar, transformar, calcular taxas e auditar a procedência.
          
      
      
          Código-fonte no GitHub — leia como cada número é calculado, ou relate um problema. Licença AGPL-3.0; peças de terceiros em Licenças.
          
      
          A decodificação do formato .DBC usa @precisa-saude/datasus-dbc; os pacotes .zip do portal passam por fflate, e a consulta SQL por DuckDB-WASM.
          
      
          Seus dados não saem deste aparelho: a leitura e o cálculo acontecem no navegador. Projeto não oficial, sem afiliação ao DATASUS ou ao Ministério da Saúde. Código sob licença AGPL-3.0.

      Prévia
      
          Totais pelo TabNet
          
      
          Uma conferência antes de baixar: o DATASUS soma no servidor dele e devolve só o resultado, em segundos. Serve para confirmar que o conjunto é este — não substitui o microdado, que é o que permite filtrar, transformar e investigar registro a registro.
          
      
          Esta é a única parte do TabSis que manda algo para fora. A pergunta viaja até um servidor do governo. O caminho normal baixa o arquivo e tabula neste aparelho, sem contar a ninguém o que você quis saber.
